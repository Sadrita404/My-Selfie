### My Selfie is an web based filter application which is use to take picture from the web cam and later we can download it as an Png image and use it ..

---

## Inspo:

For this Project I take my referance like good filter application like instagram , snapchat , etc . Where we can use the fiter on our face and take good picture .

---

## Why I built it:
I want to build something on top of this filter app so I make it from scrtch and I like it how it is turned out and I will add more filter in the future .

---

  |Tech Stack|
  |:--|
  | HTML |

---

## Features

* Can take picture with filter 
* There are 13 filters in the website 
* We can Mirror our Image .
* We also have an MonoChrome Filter 
* We can save our Picture as .png format

---

## To run it locally 
* 1) Fork the repo 
* 2) Open the file in your code editor (VS Code )
* 3) Open The Terminal 
* 4) Write - open index.html (Mac) , start index.html (Windows) , xdg-open index.html (Linux)
